
# 문장 기반 어휘 학습 모달 UI 설계

## 1. 메인 화면 - 문장 터치 인터랙션

### 1.1 터치 상태 피드백

```
기본 상태:
┌─────────────────────────────────────┐
│ 사람은 감각을 쓰면 지식을 얻고,      │
│ 안 쓰면 모르게 돼요.                │
└─────────────────────────────────────┘

길게 누르는 중 (1초+):
┌─────────────────────────────────────┐
│ 📚 사람은 감각을 쓰면 지식을 얻고,   │ (배경색 변화)
│ 안 쓰면 모르게 돼요.                │
│ [●●●○○] Loading...                 │
└─────────────────────────────────────┘
```

## 2. 어휘 리스트 모달 (1단계)

### 2.1 모달 헤더

```
┌─────────────────────────────────────┐
│ [×] 어려운 어휘 학습하기    [🔊 문장읽기] │
│ "사람은 감각을 쓰면 지식을 얻고..."    │
├─────────────────────────────────────┤
```

### 2.2 어휘 리스트 영역

```
│ 📝 총 3개의 어려운 어휘가 있어요       │
├─────────────────────────────────────┤
│                                     │
│  1️⃣ 감각 (중급)                     │
│    ┌─────────────────────────────┐   │
│    │ 뜻: 보고 듣고 느끼는 능력     │   │
│    │ [✏️ 쓰기 연습하기]            │   │
│    └─────────────────────────────┘   │
│                                     │
│  2️⃣ 지식 (고급)                     │
│    ┌─────────────────────────────┐   │
│    │ 뜻: 배움을 통해 얻은 앎      │   │
│    │ [✏️ 쓰기 연습하기]            │   │
│    └─────────────────────────────┘   │
│                                     │
│  3️⃣ 모르게 (중급)                   │
│    ┌─────────────────────────────┐   │
│    │ 뜻: 알지 못하게 되는 것      │   │
│    │ [✏️ 쓰기 연습하기]            │   │
│    └─────────────────────────────┘   │
│                                     │
└─────────────────────────────────────┘
```

## 3. 개별 어휘 학습 모달 (2단계)

### 3.1 어휘 상세 화면

```
┌─────────────────────────────────────┐
│ [←] "감각" 학습하기            [1/3] │
├─────────────────────────────────────┤
│                                     │
│        💡 단어 이해하기              │
│    ┌─────────────────────────────┐   │
│    │                            │   │
│    │        감각                │   │
│    │    (느끼는 능력)            │   │
│    │                            │   │
│    │ 예문: 눈으로 보는 것도      │   │
│    │       하나의 감각이에요     │   │
│    │                            │   │
│    └─────────────────────────────┘   │
│                                     │
│        [🔊 듣기] [📝 쓰기 연습]       │
│                                     │
└─────────────────────────────────────┘
```

### 3.2 음소 분해 화면

```
┌─────────────────────────────────────┐
│ 🔤 "감각" 글자 나누기               │
├─────────────────────────────────────┤
│                                     │
│      감        각                   │
│   ┌─────┐   ┌─────┐                │
│   │  감  │   │  각  │                │
│   └─────┘   └─────┘                │
│                                     │
│ 각 글자를 눌러서 분해해보세요!       │
│                                     │
│ [감]을 누르면:                      │
│ ㄱ(자음) + ㅏ(모음) + ㅁ(받침) = 감  │
│                                     │
│        [🎯 쓰기 연습 시작하기]        │
│                                     │
└─────────────────────────────────────┘
```

## 6. 난독증 친화적 디자인 특징

### 6.1 색상 및 시각적 요소

- **어려운 어휘**: 노란색 하이라이트 (`#FFE082`)
- **자음**: 파란색 (`#2196F3`)
- **모음**: 빨간색 (`#F44336`)
- **받침**: 초록색 (`#4CAF50`)
- **배경**: 부드러운 회색 (`#F5F5F5`)

### 6.2 텍스트 설정

- **글꼴**: OpenDyslexic 또는 나눔스퀘어
- **크기**: 제목 24px, 본문 18px, 버튼 20px
- **간격**: 줄간격 1.5배, 글자간격 0.05em

### 6.3 인터랙션

- **터치 영역**: 최소 48px 높이
- **피드백**: 터치 시 즉시 시각/햅틱 피드백
- **로딩**: 1초 롱터치 시 진행률 표시
