## 스키마 개요

이 데이터베이스 스키마는 난독증이 있는 학생들을 위해 PDF 교안을 변환하고 관리하기 위한 구조를 제공합니다. 기존 코스 중심 구조에서 문서와 페이지 중심 구조로 재설계되었습니다.

## 테이블 구조

### 1. 문서(Documents) 테이블
문서 테이블은 업로드된 PDF 교안의 메타데이터와 처리 상태를 저장합니다.

```sql
CREATE TABLE public.documents (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    teacher_id BIGINT NOT NULL REFERENCES public.teachers,
    title VARCHAR(255) NOT NULL,
    original_filename VARCHAR(255) NOT NULL,
    file_path VARCHAR(500) NOT NULL,
    file_size BIGINT,
    mime_type VARCHAR(100),
    page_count INTEGER,
    grade VARCHAR(255)
        CONSTRAINT documents_grade_check CHECK (grade::text = ANY
            (ARRAY['GRADE_1'::character varying, 'GRADE_2'::character varying, 
                   'GRADE_3'::character varying, 'GRADE_4'::character varying, 
                   'GRADE_5'::character varying, 'GRADE_6'::character varying])::text[]),
    subject_path VARCHAR(255),
    process_status VARCHAR(50) DEFAULT 'PENDING' NOT NULL
        CONSTRAINT documents_status_check CHECK (process_status::text = ANY
            (ARRAY['PENDING'::character varying, 'PROCESSING'::character varying, 
                   'COMPLETED'::character varying, 'FAILED'::character varying])::text[]),
    state VARCHAR(255),
    type VARCHAR(255),
    created_at TIMESTAMP(6) NOT NULL,
    updated_at TIMESTAMP(6) NOT NULL,
    metadata JSONB
);
```

### 2. 페이지(Pages) 테이블
페이지 테이블은 문서를 구성하는 개별 페이지의 내용과 처리된 결과를 저장합니다.

```sql
CREATE TABLE public.pages (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    document_id BIGINT NOT NULL REFERENCES public.documents ON DELETE CASCADE,
    page_number INTEGER NOT NULL,
    original_content TEXT,
    processed_content JSONB NOT NULL,
    processing_status VARCHAR(50) DEFAULT 'PENDING' NOT NULL
        CONSTRAINT pages_status_check CHECK (processing_status::text = ANY
            (ARRAY['PENDING'::character varying, 'PROCESSING'::character varying, 
                   'COMPLETED'::character varying, 'FAILED'::character varying])::text[]),
    section_title VARCHAR(255),
    reading_level INTEGER,
    word_count INTEGER,
    complexity_score FLOAT,
    created_at TIMESTAMP(6) NOT NULL,
    updated_at TIMESTAMP(6) NOT NULL,
    UNIQUE (document_id, page_number)
);
```

### 3. 페이지 용어 설명(Page Tips) 테이블
페이지에 포함된 어려운 용어나 개념에 대한 설명을 저장합니다.

```sql
CREATE TABLE public.page_tips (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    page_id BIGINT NOT NULL REFERENCES public.pages ON DELETE CASCADE,
    term VARCHAR(255) NOT NULL,
    simplified_explanation TEXT NOT NULL,
    term_position JSONB,
    term_type VARCHAR(50) NOT NULL
        CONSTRAINT page_tips_type_check CHECK (term_type::text = ANY
            (ARRAY['DIFFICULT_WORD'::character varying, 'COMPLEX_CONCEPT'::character varying, 
                   'ABSTRACT_IDEA'::character varying, 'TECHNICAL_TERM'::character varying])::text[]),
    visual_aid_needed BOOLEAN DEFAULT FALSE,
    read_aloud_text TEXT,
    created_at TIMESTAMP(6) NOT NULL,
    updated_at TIMESTAMP(6) NOT NULL
);
```

### 4. 페이지 이미지(Page Images) 테이블
페이지에 포함된 시각적 요소와 추가된 시각화 자료를 저장합니다.

```sql
CREATE TABLE public.page_images (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    page_id BIGINT NOT NULL REFERENCES public.pages ON DELETE CASCADE,
    image_url VARCHAR(500) NOT NULL,
    image_type VARCHAR(50) NOT NULL
        CONSTRAINT page_images_type_check CHECK (image_type::text = ANY
            (ARRAY['CONCEPT_VISUALIZATION'::character varying, 'DIAGRAM'::character varying, 
                   'COMPARISON_CHART'::character varying, 'EXAMPLE_ILLUSTRATION'::character varying])::text[]),
    concept_reference VARCHAR(255),
    alt_text TEXT,
    position_in_page JSONB,
    created_at TIMESTAMP(6) NOT NULL,
    updated_at TIMESTAMP(6) NOT NULL
);
```

### 5. 학생 페이지 진행(Student Page Progress) 테이블
학생이 각 페이지를 학습한 진행 상황을 추적합니다.

```sql
CREATE TABLE public.student_page_progress (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    student_id BIGINT NOT NULL REFERENCES public.students,
    page_id BIGINT NOT NULL REFERENCES public.pages,
    is_completed BOOLEAN DEFAULT FALSE,
    reading_time_seconds INTEGER DEFAULT 0,
    last_viewed_at TIMESTAMP(6),
    difficulty_rating SMALLINT,
    notes TEXT,
    created_at TIMESTAMP(6) NOT NULL,
    updated_at TIMESTAMP(6) NOT NULL,
    UNIQUE (student_id, page_id)
);
```

### 6. 페이지 접근성 설정(Page Accessibility Settings) 테이블
각 학생의 문서별 접근성 및 가독성 설정을 저장합니다.

```sql
CREATE TABLE public.page_accessibility_settings (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    student_id BIGINT NOT NULL REFERENCES public.students,
    document_id BIGINT NOT NULL REFERENCES public.documents,
    font_family VARCHAR(100) DEFAULT 'OpenDyslexic',
    font_size INTEGER DEFAULT 16,
    line_spacing FLOAT DEFAULT 1.5,
    letter_spacing FLOAT DEFAULT 0.1,
    word_spacing FLOAT DEFAULT 0.2,
    color_scheme VARCHAR(50) DEFAULT 'LIGHT' NOT NULL
        CONSTRAINT color_scheme_check CHECK (color_scheme::text = ANY
            (ARRAY['LIGHT'::character varying, 'DARK'::character varying, 
                   'SEPIA'::character varying, 'CUSTOM'::character varying])::text[]),
    highlight_current_line BOOLEAN DEFAULT TRUE,
    text_color VARCHAR(30) DEFAULT '#000000',
    background_color VARCHAR(30) DEFAULT '#FFFFFF',
    created_at TIMESTAMP(6) NOT NULL,
    updated_at TIMESTAMP(6) NOT NULL,
    UNIQUE (student_id, document_id)
);
```

### 7. 학생 문서 할당(Student Document Assignments) 테이블
교사가 학생에게 할당한 문서와 그 상태를 관리합니다.

```sql
CREATE TABLE public.student_document_assignments (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    student_id BIGINT NOT NULL REFERENCES public.students,
    document_id BIGINT NOT NULL REFERENCES public.documents,
    assigned_by BIGINT NOT NULL REFERENCES public.teachers,
    current_page_number INTEGER DEFAULT 1,
    assigned_at TIMESTAMP(6) NOT NULL,
    due_date TIMESTAMP(6),
    completion_status VARCHAR(50) DEFAULT 'NOT_STARTED' NOT NULL
        CONSTRAINT completion_status_check CHECK (completion_status::text = ANY
            (ARRAY['NOT_STARTED'::character varying, 'IN_PROGRESS'::character varying, 
                   'COMPLETED'::character varying])::text[]),
    total_learning_time INTEGER DEFAULT 0,
    created_at TIMESTAMP(6) NOT NULL,
    updated_at TIMESTAMP(6) NOT NULL,
    UNIQUE (student_id, document_id)
);
```

## 인덱스
효율적인 조회를 위한 인덱스가 추가되었습니다.

```sql
CREATE INDEX idx_documents_teacher_id ON public.documents(teacher_id);
CREATE INDEX idx_documents_grade ON public.documents(grade);
CREATE INDEX idx_documents_status ON public.documents(process_status);

CREATE INDEX idx_pages_document_id ON public.pages(document_id);
CREATE INDEX idx_pages_status ON public.pages(processing_status);

CREATE INDEX idx_page_tips_page_id ON public.page_tips(page_id);
CREATE INDEX idx_page_images_page_id ON public.page_images(page_id);

CREATE INDEX idx_student_page_progress_student ON public.student_page_progress(student_id);
CREATE INDEX idx_student_page_progress_page ON public.student_page_progress(page_id);

CREATE INDEX idx_student_doc_assignment_student ON public.student_document_assignments(student_id);
CREATE INDEX idx_student_doc_assignment_document ON public.student_document_assignments(document_id);
```

## processed_content의 JSON 구조
페이지 테이블의 `processed_content` 컬럼은 다음과 같은 JSON 구조를 가집니다:

```json
{
  "sections": [
    {
      "type": "heading",
      "content": "생태계와 환경",
      "level": 1
    },
    {
      "type": "paragraph",
      "content": "생태계는 생물과 환경으로 이루어져 있습니다.",
      "tags": ["핵심 개념"]
    },
    {
      "type": "difficult_term",
      "term": "생태계",

    },

    "font_size": 18,
    "line_spacing": 1.5,
    "letter_spacing": 0.1,
    "recommended_font": "OpenDyslexic"
  }
}
```

## 주요 쿼리 예시
### 1. 교사별 문서 목록 조회
```sql
SELECT id, title, original_filename, process_status, page_count, created_at
FROM public.documents
WHERE teacher_id = ?
ORDER BY created_at DESC;
```

### 2. 특정 문서의 페이지 목록 조회

```sql
SELECT id, page_number, section_title, processing_status, complexity_score
FROM public.pages
WHERE document_id = ?
ORDER BY page_number;
```

### 3. 특정 페이지의 상세 내용과 관련 정보 조회

```sql
-- 페이지 내용 조회
SELECT p.* 
FROM public.pages p
WHERE p.id = ?;

-- 페이지 관련 용어 설명 조회
SELECT pt.*
FROM public.page_tips pt
WHERE pt.page_id = ?;

-- 페이지 관련 이미지 조회
SELECT pi.*
FROM public.page_images pi
WHERE pi.page_id = ?;
```

### 4. 학생별 할당된 문서 조회

```sql
SELECT d.id, d.title, d.subject_path, sda.current_page_number, sda.completion_status
FROM public.student_document_assignments sda
JOIN public.documents d ON sda.document_id = d.id
WHERE sda.student_id = ?
ORDER BY sda.assigned_at DESC;
```

### 5. 학생의 문서별 진행 상황 조회

```sql
SELECT 
    d.title,
    d.page_count,
    COUNT(spp.id) AS completed_pages,
    SUM(spp.reading_time_seconds) AS total_reading_time
FROM public.student_document_assignments sda
JOIN public.documents d ON sda.document_id = d.id
JOIN public.pages p ON p.document_id = d.id
LEFT JOIN public.student_page_progress spp ON spp.page_id = p.id AND spp.student_id = sda.student_id
WHERE sda.student_id = ?
GROUP BY d.id, d.title, d.page_count;
```

## 스키마 설계 특징

1. **문서-페이지 중심 구조**: 교육 자료는 문서와 페이지 단위로 관리됩니다.
2. **난독증 친화적 요소**: 용어 설명, 시각 자료, 접근성 설정이 포함되어 있습니다.
3. **학생 진행 추적**: 페이지별 학습 진행 상황과 전체 문서 완료 상태를 모두 추적합니다.
4. **유연한 콘텐츠 구조**: JSON 형식으로 다양한 콘텐츠 형식과 레이아웃을 지원합니다.
5. **인덱스 최적화**: 자주 사용되는 쿼리에 대한 인덱스가 추가되어 있습니다.

이 스키마를 통해 PDF 교안을 페이지별로 나누어 저장하고, 학생들이 자신에게 맞는 접근성 설정으로 문서를 페이지별로 탐색할 수 있는 기반이 마련되었습니다.
