## 2. 데이터베이스 구조
다음 테이블을 추가하였습니다.
### 2.1 후원 테이블 (donations)

```sql

CREATE TABLE donations (

id BIGINT AUTO_INCREMENT PRIMARY KEY COMMENT '후원 ID',

user_id VARCHAR(100) NOT NULL COMMENT '사용자 ID',

amount INT NOT NULL COMMENT '후원 금액',

status VARCHAR(20) NOT NULL DEFAULT 'COMPLETED' COMMENT '상태',

created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,

INDEX idx_user_id (user_id),

INDEX idx_created_at (created_at)

) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='후원 내역';

```

### 2.2 자문 문의 테이블 (advisory_inquiry)
```sql

CREATE TABLE advisory_inquiry (

id BIGINT AUTO_INCREMENT PRIMARY KEY COMMENT '문의 ID',

name VARCHAR(50) NOT NULL COMMENT '문의자 이름',

phone VARCHAR(20) NOT NULL COMMENT '연락처',

content TEXT NOT NULL COMMENT '문의 내용',

created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

status VARCHAR(20) DEFAULT 'PENDING' COMMENT '상태',

INDEX idx_created_at (created_at)

) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='자문 문의';

```
