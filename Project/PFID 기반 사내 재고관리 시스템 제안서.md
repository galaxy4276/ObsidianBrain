## 1. 프로젝트 개요
본 프로젝트는 소규모 작업장을 대상으로 PFID 기반의 폐쇄망 재고관리 시스템을 구축하여,  
RFID 출입 정보 및 재고 사용 내역을 통합 관리함으로써 보안성과 효율성을 동시에 확보하는 것을 목표로 합니다.

---

## 2. 개발 범위 및 주요 기능

- **RFID 출입 로그 수집 및 기록**
- **장비/소모품 재고 등록 및 사용 내역 관리**
- **관리자 대시보드 제공**
  - 재고 현황
  - 출입 이력 시각화
- **모바일/데스크탑 양쪽 지원**
- **최대 10대 장비 관리에 최적화된 구조**
x`
---

## 3. 요구 사항 분석
- **운영 환경**: 오프라인 네트워크 환경(내부망)
- **사용자 수**: 작업장 인원 2~3인 기준
- **보안 요구**: RFID 태그 기반 출입 통제 및 사용 이력 로그
- **UI/UX**: 단순하고 직관적인 인터페이스
- **데이터 처리**: 실시간 동기화, 장비별 상태 모니터링 포함

---

## 4. 시스템 아키텍처 구성도
- **서버**: 내부망에 설치된 재고관리 서버
- **입력장치**: RFID 센서 (게이트 또는 장비 부착용)
- **데이터 흐름**
  1. RFID → 라즈베리파이/게이트웨이 → 서버 DB 저장
  2. 클라이언트(PC/모바일)에서 웹 기반 조회 및 제어

## 📌 1. 제품 개요
### 🎯 목적
소규모 작업장의 장비 및 소모품 재고를 RFID 기반으로 효율적이고 보안적으로 관리하기 위한 내부망 전용 PFID 시스템을 구축한다.

## 🛠️ 2. 기술 스택

| 항목     | 사용 기술                    |
| ------ | ------------------------ |
| 프론트엔드  | React.js                 |
| 백엔드    | Java Spring Boot         |
| 데이터베이스 | MariaDB                  |
| 통신 방식  | RESTful API              |
| 배포 환경  | 내부망 서버 (on-premise)      |
| 인증 방식  | 사내 전용 로그인 시스템 (ID/PW 기반) |
| 기타     | RFID 리더기 (하드웨어 연동 필요)    |

## 🧩 3. 주요 기능 목록
### 3.1 RFID 출입 통제 로그 기록
- RFID 리더기와 서버 간 실시간 로그 수집
- 출입 시간, 태그 ID, 위치 정보 저장
- 관리자 화면에서 조회 가능
### 3.2 품목 등록 및 재고 관리
- 장비 및 소모품 등록 (RFID 태그 기반)
- 입고 / 출고 / 사용 내역 기록
- 수량 기준 경고 시스템 포함
### 3.3 현황 대시보드
- 실시간 재고 현황 시각화 (Bar/Line Chart)
- 출입 이력 통계
- 자산 이동/사용 내역 요약
### 3.4 사용자 관리
- 관리자 계정 등록 및 권한 부여
- 로그 기록 열람 권한 제한
- 다중 사용자 로그인 기록 조회
