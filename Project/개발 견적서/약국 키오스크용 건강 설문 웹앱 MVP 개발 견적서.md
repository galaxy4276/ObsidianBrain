## 4. 영양제 추천 알고리즘 설명
MVP 단계에서는 다음과 같은 영양제 추천 알고리즘을 적용합니다:

1. **룰 기반 추천 시스템(Rule-based Recommendation System)**    
    - 5문항 이내의 선택형 질문을 통해 사용자의 건강 상태 및 필요 영양소를 파악
    - 미리 정의된 조건-결과 규칙(if-then rules)에 따라 영양제 추천
    - 질문 예시:
        - 성별 및 연령대
        - 주요 건강 고민 (수면, 피로, 면역력, 관절 등)
        - 평소 식습관 관련 질문
        - 운동 습관 관련 질문
        - 현재 복용 중인 약물 여부

2. **추천 로직**    
    - 각 질문의 답변에 가중치 부여
    - 가중치 합산 결과에 따라 해당 카테고리의 영양제 추천
    - 기본적인 조건부 필터링 적용
    - 3주 기간 내 구현 가능한 수준의 간소화된 알고리즘

3. **데이터 구조**
    - 영양제 기본 데이터베이스: 약 20~30개의 주요 영양제 정보 포함
    - 각 영양제별 주요 효능 및 섭취 권장 대상 정보
    - 간단한 JSON 형식으로 구조화
