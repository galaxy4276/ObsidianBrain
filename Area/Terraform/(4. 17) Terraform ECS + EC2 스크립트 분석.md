```tf
resource "aws_ecs_service" "nestjs_service" {  
	name = "nestjs-service"  
	cluster = aws_ecs_cluster.main.id  
	task_definition = aws_ecs_task_definition.nestjs.arn  
	desired_count = 1  
	  
	ordered_placement_strategy {  
		type = "binpack"  
		field = "memory"  
	}  
	  
	placement_constraints {  
		type = "memberOf"  
		expression = "attribute:app_node == true"  
	}  
	  
	load_balancer {  
		target_group_arn = aws_lb_target_group.nestjs_tg.arn  
		container_name = "nestjs"  
		container_port = tonumber(var.nestjs_port)  
	}  
}
```

`name = "nestjs-service"`
ECS 서비스이 이름을 `nestjs-service` 로 지정

`cluster = aws_ecs_cluster.main.id`
이 서비스가 실행될 ECS 클러스터의 ID를 지정
`aws_ecs_cluster.main`에서 생성된 클러스터를 참조
