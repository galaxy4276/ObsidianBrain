## 블룸 필터란?
블룸 필터는 1970년 Burton Howard Bloom이 제안한 확률적 자료구조다. 원소가 집합에 속하는지 여부를 검사하는데 사용되며, 공간 효율성을 극대화하는 대신 False Positive(거짓 양성)를 허용하는 특성을 가지고 있다. 즉, 블룸 필터는 "이 원소는 확실히 집합에 없다" 또는 "이 원소는 아마도 집합에 있다"라고 대답할 수 있다.

## 블룸 필터의 작동 원리
블룸 필터는 기본적으로 m 비트 길이의 비트 배열과 k개의 서로 다른 해시 함수로 구성된다. 작동 방식은 다음과 같다.
### 원소 추가
1. 원소를 k개의 해시 함수에 통과시켜 k개의 인덱스를 얻는다
2. 비트 배열에서 해당 인덱스 위치의 비트를 모두 1로 설정한다
### 원소 검색
1. 원소를 k개의 해시 함수에 통과시켜 k개의 인덱스를 얻는다
2. 비트 배열에서 해당 인덱스 위치의 비트가 모두 1이면 "아마도 있음"으로 판단한다
3. 하나라도 0이면 "확실히 없음"으로 판단한다

```javascript
// JavaScript로 구현한 간단한 블룸 필터 예시
class BloomFilter {
  constructor(size = 1000, hashFunctions = 3) {
    this.size = size;
    this.bits = new Array(size).fill(0);
    this.hashFunctions = hashFunctions;
  }
  
  // 해시 함수 (간단한 예시)
  hash(item, seed) {
    let hash = 0;
    for (let i = 0; i < item.length; i++) {
      hash = (hash * seed + item.charCodeAt(i)) % this.size;
    }
    return hash;
  }
  
  // 원소 추가
  add(item) {
    for (let i = 0; i < this.hashFunctions; i++) {
      const index = this.hash(item, i + 1);
      this.bits[index] = 1;
    }
  }
  
  // 원소 확인
  has(item) {
    for (let i = 0; i < this.hashFunctions; i++) {
      const index = this.hash(item, i + 1);
      if (this.bits[index] === 0) return false;
    }
    return true; // 아마도 있음
  }
}
```

## 블룸 필터의 특징
### 장점
- 공간 효율성이 매우 높다. 원소 자체를 저장하지 않고 비트만 저장한다.
- 원소 추가와 조회 연산의 시간 복잡도가 O(k)로 매우 빠르다.
- 원소가 증가해도 검색 시간이 늘어나지 않는다.
- 거짓 음성(False Negative)이 없다. 즉, "없다"고 하면 확실히 없다.

### 단점
- 원소 삭제가 기본적으로 불가능하다. (계수 블룸 필터로 해결 가능)
- 거짓 양성(False Positive)이 발생할 수 있다. 즉, 실제로는 없는데 "있을 수도 있다"고 대답할 수 있다.
- False Positive 확률은 원소 수와 비트 배열 크기에 따라 달라진다.

💡 False Positive 확률을 낮추려면 비트 배열의 크기를 늘리거나 해시 함수의 수를 조정하면 된다.

## 블룸 필터의 응용 분야
블룸 필터는 다양한 분야에서 활용되고 있다.
### 웹 캐싱 및 데이터베이스
- 캐시 미스를 줄이기 위해 데이터가 캐시에 있는지 빠르게 확인
- 데이터베이스에서 디스크 접근 전 빠른 멤버십 검사
### 네트워크 애플리케이션
- 네트워크 패킷 필터링
- URL 차단 목록 관리
- 중복 URL 방문 방지 (웹 크롤러)
### 암호화 및 보안
- 패스워드 크래킹 방지
- 악성 URL 및 스팸 필터링
### 빅데이터 처리
- 분산 데이터베이스에서 중복 데이터 검출
- MapReduce 작업에서 조인 연산 최적화
## 블룸 필터 구현시 고려사항

### 최적의 파라미터 설정
블룸 필터의 성능은 비트 배열 크기(m), 해시 함수 개수(k), 그리고 예상 원소 개수(n)에 따라 결정된다. 최적의 해시 함수 개수는 다음 공식으로 계산할 수 있다.

`k = (m/n) * ln(2)`

여기서 m은 비트 배열 크기, n은 예상 원소 개수다.
### 확장 가능한 블룸 필터
데이터 양이 증가함에 따라 확장할 수 있는 확장 가능한 블룸 필터 설계도 가능하다. 계층적 구조나 스케일링 메커니즘을 통해 구현할 수 있다.

## 마치며
블룸 필터는 메모리 효율성과 빠른 조회 성능이 필요한 시스템에서 유용하게 활용될 수 있는 자료구조다. 특히 정확한 결과보다 빠른 응답이 중요하고, False Positive가 허용 가능한 상황에서 뛰어난 선택이 된다. 대규모 데이터 처리, 캐싱, 중복 검사 등 다양한 응용 분야에서 성능 향상을 위한 강력한 도구로 자리잡고 있다.
